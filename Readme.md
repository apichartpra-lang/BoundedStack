## สเปคของ BoundedStack

### ค่านามธรรม (A)

ลำดับของจานเช่น `[จานลายสีแดง,จานไม่มีลายสีขาว,จานสีดำมีลาย]` โดยลำดับความหมาย - จานใบแรกคือใบที่เก็บก่อน

### Representation (R)

```java 
private final List<String>plates
```
### กฎที่การเก็บจานต้องรักษาไว้
- plates ต้องไม่เป็น null
- ไม่มีสมาชิกใน plates ที่เป็น  null
- ไม่มีสมาชิกใน plates ที่เป็นสตริงว่าง
- plates.size <= capacity


## งานที่ต้องทำ

### งานที่ 1 — เขียน AF, RI และ Safety from rep exposure (TODO 1–3)

เขียนเป็นคอมเมนต์ไว้เหนือ `private final List<String> plates;`

***AF*** ต้องบอกว่า `plates` **หมายถึงอะไร** ไม่ใช่บอกว่ามันเป็นตัวแปรชนิดอะไร
(plates, capacity): ที่เก็บจานที่มีความจุ capacity ใบ โดยจานที่เข้ามาแรกสุดอยู่ที่ plates.get(0) (ล่างสุด) และจานที่เข้ามาช้าสุดอยู่ที่ plates.get(size-1) (บนสุด) 



**RI** ต้องเขียนให้ครบทั้ง 5 ข้อ

**Safety from rep exposure** ให้อธิบายวิธีการป้องกันการรั่วด้วยวิธีการอะไร

## งานที่ 3 - เขียน Creator ตัวที่สอง (TODO 5)

`BoundedStack(int capacity, List<String> initial)` สร้างกองจานจากรายชื่อจานเริ่มต้นที่ให้มา

- ถ้า `capacity` <= 0 หรือ `initial` ผิดเงื่อนไข (เป็น `null`, มีจานเป็น `null` หรือสตริงว่าง, ขนาดเกิน `capacity`) ให้ `throw new IllegalArgumentException` พร้อมข้อความอธิบาย
- **ห้ามเก็บ reference ของ `initial` ตรง ๆ** ต้องคัดลอกเข้ามาใหม่ด้วย `new ArrayList<>(initial)` เพื่อป้องกันปัญหา `Rep Exposure`
- เรียก `checkRep()` ก่อนจบเมธอด

>**ทำไมต้อง throw ไม่ใช่ assert?**
>`initial` มาจาก client ถ้าเขาส่งค่าผิดคือ **ความผิดของ client** ต้องใช้ Exception ในการจัดการ
>ส่วน `assert` ใช้ตรวจ rep ภายในของเราเอง ซึ่งถ้าพังแปลว่า *เราเขียนบั๊ก*
>อีกเหตุผลคือ `assert` จะถูกปิดอัตโนมัติเมื่อไม่ได้ใส่ `-ea` ตอนรันจริง ทำให้ไม่มีการตรวจเช็กค่า
